## Quick Start (Local)
1. ติดตั้งไลบรารี: `pip install -r requirements.txt`
2. รันเซิร์ฟเวอร์: `uvicorn main:app --reload`
3. เปิดเบราว์เซอร์ไปที่: `http://127.0.0.1:8000`
